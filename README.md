# Turbo Golf: Spiritual Successor

A modern web-based spiritual successor to the 2012 Flash game "Turbo Golf".

## Tech Stack
- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS (Cinematic Brutalist Aesthetic)
- **Game Engine**: Phaser.js (Matter.js Physics)
